Measured power of the HaLow node

XIAO ESP32-S3 with the Wio-WM6180 hat (Quectel FGH100M-H, MM6108). Hat off measured on 2026-10-09, hat on on 2026-10-11. With the link up but idle the node draws 348.8 mW, of which 217.0 mW is the radio. Full-load TCP uplink costs from 132 nJ/bit (MCS5) up to 441 nJ/bit (MCS0).

Read these before using the numbers
  • verifiedinferredZero offset: in deep sleep the INA219 reads -2.54 mA (hat off) and -2.47 mA (hat on). Real deep-sleep current is far smaller than one current step, so every absolute value here reads low by about that amount. Hat-on minus hat-off differences are not affected.
  • verifiedLight and deep sleep are below the 1 mA current step of the 0.01 Ω shunt. They need a 1 Ω shunt pass or the Joulescope.
  • verifiedinferredTX at MCS6 and MCS7 failed: only 44.7 % and 25.0 % of frames got through, while the Pi read RSSI -18 dBm. The link is far too strong, likely overloading the receiver. Repeat with more attenuation.
  • verifiedRX received no data, and the Pi's stage file stayed empty. Cause not found yet; RX is shown in the table only.
  • verifiedWith the hat fitted, E_BUSY_MEM draws 11.0 mW more; the other ESP stages change much less. Not explained yet.
  • openLink-up idle is 348.8 mW on this bench, but the paper's Table I gives P0 = 0.481 W. Explain this gap before refining the energy model.
